# madhuwrites ✦ fairytale version

A moonlit, lantern-lit poetry website with magical golden fireflies, shooting stars, tulips, a soft pink/lilac dusk palette, music controls and a simple poem system.

## Upload to GitHub Pages
1. Replace your existing `index.html` and `style.css` with these files.
2. Keep your existing `poems.js` if you already added your poems, or use the included one.
3. Optional: add `music.mp3` to the same folder.
4. Commit the changes and refresh your GitHub Pages site.

## Add poems
Edit only `poems.js`. Each poem has a title, category, symbol, tone, excerpt and full poem text.

The visual direction is original fairytale/lantern-night inspired rather than using copyrighted movie artwork or characters.
