# madhuwrites — fairytale night edition

This version is deliberately image-led so the homepage matches the dreamy reference: twilight sky, moon, shooting stars, warm magical lights, tulips, Polaroids, books, lantern and film strip.

## GitHub Pages
Upload these files directly to the root of your `madhuwrites.github.io` repository:

- `index.html`
- `style.css`
- `poems.js`
- `madhuwrites-hero-bg.jpg`

Keep `poems.js` if you already added your poems. Do not put these inside another folder.

Optional music: add a file named `music.mp3` to the same folder.
