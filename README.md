# madhuwrites ✦

A whimsical poetry website for GitHub Pages.

## Uploading to GitHub

1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload `index.html` and `style.css`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch → main → / (root)**.
5. Save and open `https://YOURUSERNAME.github.io`.

## Your own poems

The sample cards are placeholders. Search `poem-card` in `index.html` and replace the titles, descriptions and text passed to `openPoem(...)` with your own work.

## Music button

The website includes a music toggle. To use it:

1. Choose an audio file you have the right to use.
2. Rename it `music.mp3`.
3. Put it in the same folder as `index.html`.
4. Upload it to GitHub with the other files.

Browsers generally block websites from autoplaying audio, so the music starts only after the visitor taps the button.

## Fireflies

The fireflies are generated automatically with JavaScript and require no image files.
